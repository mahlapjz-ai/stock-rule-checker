## 三、冲突观点及处理方式（冲突矩阵）

### CM01 补仓触发阈值：4% vs 20%-30%

| 项 | 内容 |
|----|------|
| 甲方 | 短线操作的风险控制：**跌超4%**即用等量资金补仓一次（只能补一次） |
| 乙方 | 一招学会解套实战技巧：跌5%左右**不用补**（反弹即解套），跌**20%-30%以上**才考虑补仓 |
| 矛盾点 | 补仓的触发跌幅相差近一个数量级 |
| 能否条件化 | **能**。甲方前提是"短线+轻仓+资金分等份+只补一次"（试错性摊薄）；乙方前提是"中长线解套+大盘处于相对低位/非下跌趋势"（趋势性补仓）。适用条件互斥 |
| 处理 | 分别保留为 **R020**（4%短线补仓，weight=1，严格条件）与 **R021**（20-30%深回调补仓，weight=1，须大盘企稳）；均不进入高权重 |

### CM02 追涨 vs 不追高

| 项 | 内容 |
|----|------|
| 甲方 | 短线操作的风险控制："人气旺盛的市道宜于追涨" |
| 乙方 | 微信截图/尾盘买入法/复盘："高开不要追等回踩""尾盘急拉太高不追""不建议追涨买入" |
| 矛盾点 | 一个鼓励追涨、一个反对追高 |
| 能否条件化 | **能**。甲方限定"牛市/交投活跃/热点区域"且配合轻仓与突破介入法；乙方针对"已大幅高开""尾盘无理由急拉"的兑现场景 |
| 处理 | 甲方并入 **R010**（突破买入，条件限定）；乙方的操作逻辑保留为 **R024**（高开不追低开低吸）与 **R019**（尾盘急拉预警） |

### CM03 金叉买 vs 金叉卖（同为"短线上穿长线"）

| 项 | 内容 |
|----|------|
| 甲方 | 教材一/五/八册：短均线上叉长均线（长线走平向上）→ 买入 |
| 乙方 | 教材十册 MCX10：133日线向下时，4日线上穿133日线 → 最后逃命时机 |
| 矛盾点 | 同为金叉，方向完全相反 |
| 能否条件化 | **完全能**。判据就是长期均线的运行方向：向上=金角买点，向下=反压逃命点 |
| 处理 | 拆分为 **R004**（金角买入）与 **R006**（长期均线反压卖出），条件互斥并在规则中互相注明 |

### CM04 做T vs 持股不动

### CM05 换手率阈值：近5日累计40% vs 单日5%-10%
