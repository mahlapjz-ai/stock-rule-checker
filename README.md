# WB-投资试水 · 股票规则一致性检测器

本项目从 `投资学习/` 目录下的 44 篇股票分析/交易文档中，提炼出 26 条可计算的交易规则（`rules.json`），并构建了一个「规则一致性检测器」——一个单文件 HTML，用腾讯自选股行情数据对个股做规则打分。它只检测「当前行情与历史文档规则的一致程度」，**不预测未来涨跌**；评分是规则触发的一致性度量，不是买卖信号。

**产出物**（位于 `投资学习/提炼结果/`）：

- `规则一致性检测器.html` —— 规则一致性检测器（26 条规则打分、K线、规则明细、回测）
- `rules.json` —— 26 条主规则库；`viewpoint_cards.json` —— 30 张观点卡片（逐篇可追溯）
- `文档提炼报告.md` —— 文件清单、一致观点、冲突矩阵、被排除观点及理由
- `回测说明.md` —— 回测口径与「回测仅检验、未校准」声明
- `prediction_model.py` / `prediction_panel.py` / `预测模型说明.md` —— 预测模型诊断（结论：技术指标无预测力）

**已知局限**：

1. 技术指标对未来涨跌无预测力（已四重验证，样本外 AUC≈0.5，详见预测模型说明）；
2. 8 个加密文件未纳入（7 个加密 PDF + 1 个加密 Word，需密码）；
3. 规则来源单一（约 22/30 篇来自「成总团队」同一体系，存在同源一致风险）。
